# Checkgrade — ระบบตรวจสอบผลการเรียนออนไลน์

Next.js 15 + Tailwind CSS 4 + Supabase, deploy บน Vercel. ออกแบบสำหรับมือถือ

## ผู้ใช้
- **นักเรียน** `/student` — กรอกเลขประจำตัว → ยืนยันชื่อ/ชั้น → ดูผลทุกวิชา, GPA, แชร์การ์ด, ออกจากระบบอัตโนมัติเมื่อไม่ใช้งาน 3 นาที
- **ครู** `/teacher` — ลงทะเบียน/เข้าสู่ระบบ, อัปโหลด Excel (ชีต หน้าหลัก, เทอม1, เทอม2) ตรวจ/แก้ก่อนบันทึก, แก้ไข/ลบได้เฉพาะของตัวเอง, แดชบอร์ดสรุป
- **แอดมิน** `/admin` — ผู้ลงทะเบียนคนแรกเป็นแอดมินอัตโนมัติ ตั้งค่าระบบ เวลาเปิด-ปิด (นับถอยหลัง) โลโก้ สไตล์ 3 แบบ รายชื่อครู ประวัติการใช้งาน ลิงก์+QR

## รองรับผู้ใช้พร้อมกัน
`/api/student/[code]` แคชที่ CDN ของ Vercel (s-maxage 120s) ต่อเลขประจำตัว ฐานข้อมูลถูกเรียกเพียงครั้งเดียวต่อคนต่อช่วงแคช

## ติดตั้ง
1. รัน `supabase/migrations/0001_init.sql` ใน Supabase SQL editor
2. Supabase → Authentication → Providers → Email: ปิด "Confirm email" (ถ้าไม่ต้องการให้ครูยืนยันอีเมล)
3. ตั้ง env ตาม `.env.example` แล้ว `npm run dev`
